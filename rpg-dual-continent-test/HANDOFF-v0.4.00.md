## 三、磐甲風刃蠍

### 狀態流程

```
WALK（巡邏）
 ├─ 小V在正前方近距離 → SLAM：Charge 0.7 秒 → Swing 0.13 秒 → Impact 0.3 秒（前 5 幀有判定）→ Recover 0.9 秒
 ├─ 小V在正前方 150～560px → WIND SLASH：Charge 0.5 秒 → Gather 0.6 秒 → Release 0.3 秒（第 3 幀放出風刃）→ Recover 0.7 秒
 ├─ 小V在正前方、招式還在冷卻 → GUARD（舉盾至少 0.6 秒後可以改出招；破甲後 Guard 只有 1 秒）
 └─ 小V在背後 → TURN（0.8 秒後才轉身）
任何招式結束 → 至少 1.17 秒後才能開始下一招（Recover 一定先做完）
被打到（巡邏／舉盾／轉身／Charge／Gather）→ HURT 硬直 0.37 秒（已經出手的 Swing／Impact／Release 不會被打斷）
最後一格盔甲破掉 → BREAK 0.9 秒 → 回到 WALK（之後就是破甲階段）
```

- Slam 冷卻 2.8 秒，Wind Slash 冷卻 4.5 秒。

### 破甲前後

| | 破甲前（盔甲 2） | 破甲後 |
|---|---|---|
| 正面氣球劍 | 擋下：不扣盔甲、不扣本體；播 `boss_sword_block.mp3`；「擋！」火花；**仍扣劍耐久 1** | 扣本體 1（就算正在 Guard） |
| 正面氣球槌 | 盔甲 −1 | 本體 −1 |
| 背後攻擊 | 本體 −1 | 本體 −1 |
| 招式 | Guard、Slam、Wind Slash | Guard、Slam、Wind Slash（全部保留） |
| 外觀 | 正常；Guard 時正前方金色弧光 | Exposed 外觀；出招時用招式圖 |
| 頭頂 | 🛡 2 格＋❤ 3 格 | 只有 ❤ |

- 破甲瞬間：命中停頓 6 步、石甲碎片、盾牌碎片、「破甲！」1.3 秒後消失、硬直 0.9 秒。
- 「弱點！」不再永久顯示。
- 盔甲不會長回來。

### Slam 判定

- 判定範圍：螯鉗落點（身體正前方）往前 50px、往後 14px、高 52px。

- 雨傘：沿用既有的近戰主動格擋。按住格擋、面向磐甲時，雨傘碰到磐甲身體或 Slam 範圍 → 擋下、雨傘 −1；磐甲只會被推到傘前，不會被彈飛。

## 四、大型風刃（Wind Slash）

- 獨立物件（放在 `wsBlades`，標記 `big`），水平飛行，不追蹤。速度 4.6 px／步，最遠 900px。
- 原圖朝左；往右飛由程式鏡像。
- 碰撞框只取可見的主要風刃：前端往後 85px、高 28px。

| 階段 | 規則 |
|---|---|
| 去程 | 只把小V當目標。其他蠍子（普通、疾風、磐甲）、其他敵人、可倒樹木全部穿過，風刃不消失 |
| 命中小V | 扣 1 格（和一般風刃相同），風刃消失；受擊無敵中會穿過 |
| 雨傘成功格擋 | 小V不受傷、雨傘 −1；風刃改成小V的攻擊，**水平反向**飛回（速度 ×1.1），不是一般風刃的斜上 50° |
| 回程 | 只打回程路線上**第一個**碰到的有效目標（敵人或還站著的可倒樹），打完就消失；路上沒有東西才會打回磐甲 |
| 打到敵人 | 走該敵人自己的受擊規則：普通蠍子 1 點；疾風 1 點；磐甲盔甲完整＋正面 → 盔甲 −1，其他 → 本體 −1。擊倒時旋轉飛出（不會再撞傷別隻） |
| 打到樹 | 一般樹往風刃前進的方向倒；坑邊樹照舊往坑倒 |
| 音效 | 飛行聲（去程＋反彈）沿用風刃蠍子的飛行聲；命中、出界才停 |
| 擊倒後 | 磐甲被擊倒時，牠還在去程的風刃會消失（擊倒後不會再攻擊小V） |

## 五、疾風蠍子怪

- 頭頂 ❤ 2 格。劍每次 −1；氣球槌照舊一下擊飛。
- 準星：搜尋 0.6 秒（目標跟著小V，準星左右擺動 70→34px）→ 收斂 0.4 秒（擺動縮到 0）→ 鎖定 0.27 秒（準星停住、「LOCK」）→ 衝刺。
- 衝刺停點＝鎖定完成時的準星位置；左右擺動只是畫面，不是停點。
- 準星高度固定在疾風所在的地面／平台，小V跳起來也不變。
- 瞄準音效 `swift_scorpion_targeting.mp3`：
  - 搜尋開始時播放，循環播放。
  - 衝刺、被打斷、擊倒、暫停、換關、重新開始時停止。
  - 畫面上有幾隻疾風同時瞄準，都只有一個聲源。

## 六、HP、接地、Hurt／Defeat

- **頭頂 HP**：沿用重甲蠍子的格狀血條（黑底、綠／橘／紅格），盔甲是金色格。位置在 Idle 姿勢的頭頂上方，固定大小，不會跟著角色放大。
- **接地**：兩種蠍子每一個動作都量測了「後方腳尖」，以這一點接地。磐甲 16 個動作、疾風 8 個動作，換動作不會浮起或陷入。只改畫面，碰撞、重力、攻擊範圍都不變。

| 項目 | 疾風 | 磐甲 |
|---|---|---|
| Hurt 圖顯示 | 26 幀（0.43 秒） | 26 幀（0.43 秒） |
| 受擊硬直（不能移動／出招） | 24 幀（0.4 秒） | 22 幀（0.37 秒） |
| 受擊保護 | 原本 0.13 秒 | 原本 0.3 秒（本體）／0.4 秒（盔甲） |
| Defeat（劍、倒樹、反彈風刃擊倒） | 白閃 8 幀 → HardStun 圖 40 幀 → 淡出 22 幀（1.17 秒） | 白閃 8 幀 → Defeat 圖 40 幀 → 淡出 22 幀（1.17 秒） |
| 槌子擊飛 | 前 20 幀 Hurt，之後 Defeat | 同左 |

- 擊倒獎勵與擊倒紀錄在擊倒當下結算一次；延長的 Defeat 只是畫面。

## 八、F8 凍結

- 原因：v0.3.99 把開發者模式改成只認網址 `?devtools=1`（修正「已加入開發測試背包」）。以前用瀏覽器裡的開發者開關 `balloonV_devTools=1` 開啟的 F8，在一般網址下就不作用了。
- 修正：
  - `?devtools=1`：F8、F4、F5 照舊。
  - 一般網址，但這台瀏覽器有 `balloonV_devTools=1`：只開放 F8 凍結／解除。不會變成開發者存檔、不開其他工具。
  - 一般玩家（沒有開關）：F8 不作用。
