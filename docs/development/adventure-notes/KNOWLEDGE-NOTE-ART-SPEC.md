# 《小V的冒險知識筆記》正式美術規範

本文件是《小V的冒險知識筆記》系列的永久美術規範。未來所有冒險知識筆記都必須比照本規範。

## 唯一正式系列參考

- 第一份定稿：**風之峽谷的飛行秘密**（使用者已驗收）
- 原始附件名稱：`風之峽谷的飛行秘密(3).png`
- 正式檔案：`assets/adventure/notes/knowledge_note_projectile_motion.png`
- 遊戲內 ID：`knowledgeNoteProjectileMotion`（3-4 風之峽谷）
- 定稿以原始 PNG 收錄：不重新生成、不修改字形、圖解、箭頭與飛行軌跡，不裁切、不拉伸、不重新上色、不加編號。

## 固定規格

- 系列名稱：小V的冒險知識筆記
- 不使用系列編號（遊戲內也不顯示 No.001 等編號）
- 橫式單張舊牛皮紙
- 泛黃、破舊、折痕、污漬及自然磨損
- 左側裝訂孔，可集結成冊
- 外部透明背景（PNG）
- 標題及文字直接寫在紙張內
- 正確繁體中文
- 自然手寫墨跡
- 鵝毛筆及墨水素描風格
- 簡筆手繪及少量上色
- 手畫箭頭、底線及必要重點標示
- 圖解優先，文字極精簡
- 搭配適當的生活實例
- 角色、服裝、髮型及道具遵守正式遊戲設定

## 禁止

- 現代資訊圖卡
- 精美商業教學海報
- 乾淨的現代文具風
- 自行創造錯誤中文字形
- 擅自更改小V角色造型
- 不正確的科學圖解
- 局部修改時破壞其他已驗收內容

## 加入遊戲的流程

1. 美術完成 → 使用者驗收（尚未驗收的新筆記不得直接加入正式遊戲）。
2. 原始 PNG 放入 `assets/adventure/notes/`（檔名用英文小寫與底線，例如 `knowledge_note_<主題>.png`），不做任何影像處理。
3. 在 `assets/adventure/adventure-notes.js` 的 `NOTES` 加一筆：固定 ID、`category: 'knowledge'`、名稱、大陸、關卡、圖片路徑、`pickupIcon: 'knowledgeBulb'`、拾取位置。
4. 拾取位置不得需要氣球小狗、骰子或付費；不得與寶箱、導風裝置或其他互動物件重疊；沒拿到也必須能通關。
5. 閱讀器與小V之家不需要修改。

## 遊戲內顯示要求（閱讀器）

- 保持原始長寬比例，完整顯示，不裁切、不拉伸；保留透明背景。
- 桌面與手機橫向都能閱讀；字太小時可按「🔍 放大」捲動查看。
- 拾取圖示：金色燈泡（`assets/adventure/ui/items/item_knowledge_note_bulb.png`），只用於冒險知識筆記。
