## Batch C2｜本機驗收

| 項目 | 結果 |
| --- | --- |
| 兩道瀑布、尺寸與銜接 | 桌機及手機橫向觸控模擬均以正常操作進入兩道瀑布，檢視角色尺寸、連續水柱與單一腳邊水花。 |
| 18A 側身及循環 | 驗證 Intro 960 ms、側身 500 ms 與 Loop 920 ms。錄影中雙向進入、側身換水幕影格、正面受驚、眨眼及手部微動；停留超過兩秒只循環 Loop。 |
| 操作、結束及雨傘 | 正常跑過水柱只經過 Intro，離開後立即無 18A。沖水時以正常切換操作撐傘，18A 停止，濕值自然降低，耐久仍為 6/6。 |
| 18B 移動、跳躍、攻擊、方向及乾燥 | 錄影包含持傘、跑、跳、攻擊和轉向。下降的濕值對應較淡的水滴，桌機第一道測至濕值 0 並核對畫面。 |
| C1 導水與資料隔離 | 兩種操作均使第二道水池升至 100%。完整 3-4、浮墊、既有風乾及隔離包回歸通過；正式存檔與 A、B 前綴探針保留。 |

共 50 項測試通過，其中關卡及隔離包 22 項，入口、稱號與骰子 28 項。實體手機待驗收。

錄影交付檔名為 `C2-desktop-start.webm`、`C2-desktop-pool.webm`、`C2-mobile-landscape-start.webm` 和 `C2-mobile-landscape-pool.webm`。
