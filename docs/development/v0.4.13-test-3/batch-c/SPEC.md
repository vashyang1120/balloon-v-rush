三、雨傘防水修正
━━━━━━━━━━━━━━━━━━━━

此項為重複退件問題。

使用者實際操作時，
明明已撐開氣球雨傘，
經過瀑布仍然溼身。

必須查明根因。

正式規則：

小V撐開氣球雨傘，
且雨傘有效攔截瀑布時，
不得因該瀑布增加潮溼值。

乾燥的小V仍維持乾燥。

已潮溼的小V不得因經過
受雨傘攔截的瀑布，
重新補滿潮溼值。

雨傘成功攔截瀑布
不消耗耐久。

未撐傘受到瀑布沖淋，
正常進入潮溼狀態。

若小V實際進入水池，
仍然會溼身，
不受持傘狀態影響。

必須檢查每次遊戲更新中：

雨傘攔截判定。
瀑布接觸判定。
潮溼數值更新。

三者的執行順序及一致性。

不得只取消視覺水滴，
卻仍然在背景增加潮溼值。

四、雨傘分流重複退件修正
━━━━━━━━━━━━━━━━━━━━

test-1及test-2均曾出現：

分流水流從頭部附近生成。
水花只停留在傘頂。
水流與傘面分離。
水流像另外發射的水砲。
分流水柱在半空中突然結束。

本次必須徹底修正。

使用既有正式雨傘分流素材，
重新確認素材方向、
錨點、尺寸及裁切方式。

正確呈現：

1. 原垂直瀑布抵達雨傘上方。

2. 水柱在真正的傘面接觸點截斷。

3. 水流沿傘面向外分流。

4. 水流由傘緣自然向外及向下落。

5. 不得出現水流向上噴射
   或像彩虹形狀的水橋。

6. 水流最終自然落至
   地面或水池。

7. 不得讓分流水柱
   在半空中突然消失。

8. 傘面下方不得仍然存在
   未被截斷的原垂直水柱。

配合新版瀑布寬度校準
實際攔截及分流水量。

兩道瀑布均須正常運作。

第二道瀑布須保留
既有導水解謎機制。

水流導入水池時，
水位才依既有規則增加。

不得因美術分流修正，
破壞既有水位及浮墊機制。
