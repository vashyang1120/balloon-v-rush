# Revision 5｜施工前調查（AUDIT）

基準：Revision 4 `b5b2f47`（Draft PR #47）。本分支 `test/adventure-v0.4.13-gameplay-polish-qa-rev5`。

## 調查結果與根本原因

| 項目 | 調查到的狀況（Revision 4） | 原因 |
|---|---|---|
| A-01 骰子不在背包 | 小V之家背包「武器」分頁只列 `durability > 0` 的配方（`h2WeaponRecipes`）；骰子沒有耐久 → 不出現。暫停背包的武器列也沒有骰子列。 | 分頁只為有耐久的武器設計 |
| A-02 雨傘上限 | `V395_BAG.caps` 沒有 `balloonUmbrella`（沒有上限） | 雨傘加入時沒有登記上限 |
| A-03 急救包文字 | 「使用後直接補滿生命。最多攜帶 1 箱。」上限已改成依背包等級，固定的「1 箱」會誤導 | 文字沒跟著 v0.3.95 背包等級更新；其他道具敘述沒有寫死上限 |
| A-04 暫停畫面 HP | `refreshAllHpDisplays` 只更新冒險 HUD；暫停畫面的愛心只在打開暫停時畫一次 | 暫停 UI 2.0 沒掛在 HP 更新點 |
| A-05 造型入口 | 商店分頁 `H2_SHOP_TABS` 含「造型・寵物配件」，內容只有「即將推出」 | 預留入口 |
| A-06 批量購買 | 上限只看背包剩餘（材料包更接近無限），不看金幣；按鈕不變灰 | `h2ShopRoom` 只算攜帶量 |
| A-07 第一大陸免費 LV2 | 第一大陸商店／暫停開發面板仍有免費 LV1／LV2 切換 | Revision 4 只移除第二大陸的副本 |
| B-01 3-2 開頭空地 | 出生點 x 100 到第一個風口 890 之間只有平台 A（420～570），沒有敵人 | 關卡配置 |
| B-02 風刃隨射手消失 | `wsUpdateBlades` 在射手死亡時移除普通風刃；`c4UpdateSlashes` 讓鎧甲風刃淡出 | 舊規則把風刃綁在射手上 |
| B-03 風刃射程 | 普通風刃最遠 900 px（`bladeMaxDist`），沒有淡出 | 舊規則 |
| C-01／C-02 樹峽谷 | A3 掉落只回到 P2，沒有受傷演出 | Revision 3 只做了「不扣血」 |
| C-03 計數漏算 | 公開網址實測時發現：從 P2 右緣「直接走下去」（沒有跳）掉進樹峽谷，不會算一次失敗；只有跳下去才會算 | 「站在 P2 上」以小V身體中心判斷，走到邊緣時中心已超出 P2，但腳還踩著，所以最後一次站立沒被記成 P2（Revision 3 的程式） |
| C-05 寶箱 | 珍貴寶箱在出口對岸 x 4427，位在主線上 | 原配置 |
| C-06 高台鏡頭 | 規則是「小V頭頂高過畫面上方 110 px 才往下移」，上限 430 px → 在 P2／P3／峽谷頂部／對岸，小V幾乎貼著畫面頂端（被 HUD 擋住），對岸甚至超出 | 鏡頭只保證頭在畫面內 |
| C-07 水池捷徑跳出槌子教學 | 捷徑的測試背包有氣球槌，但測試 RPG 存檔沒有「做出氣球槌」已讀 → `rpgHammerTutorialDue` 成立 | 捷徑存檔前置條件不完整 |
| D-01 暫停背景 | `--h2-img-continent` 只在小V之家重畫時設定；從第一大陸窗景的小V之家出發到第二大陸，暫停仍是第一大陸背景 | 背景更新點只在小V之家 |
| D-02 其他共用 UI | 只有暫停選單使用大陸背景；小遊戲背景每次依目前大陸計算；結算、失敗、背包面板沒有場景背景 | — |
| G 骰子音訊 | 兩個大陸的骰子都沒有專屬音訊；動畫固定 2×1450 ms | 新功能 |
